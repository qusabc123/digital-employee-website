什么是 Hermes

Hermes 是一个自带学习闭环的 AI Agent 框架。它不仅是一个聊天机器人，而是：

  • 能从经验中自动创建技能，在使用中改进技能
  • 能持久化知识，跨会话搜索记忆
  • 能调度定时任务，委派子代理并行工作
  • 能跑在 $5 VPS / GPU 集群 / Serverless 上
  • 支持 CLI / Telegram / Discord / Slack / WhatsApp / Signal 全平台接入

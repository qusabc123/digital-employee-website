Hermes CLI 速查

完整命令参考: https://hermes-agent.nousresearch.com/docs/reference/cli-commands

基础命令

hermes                    # 启动交互式对话

hermes --tui              # 启动现代 TUI（推荐）


hermes --cli              # 强制经典 REPL


hermes -c                 # 恢复最近会话


hermes -c "项目名"        # 按名称恢复会话


hermes --resume <id>       # 按 ID 恢复会话

一行命令模式

hermes -z "你好"           # 单次回答（无交互）

hermes -m claude-sonnet-4 -z "你好"  # 指定模型单次回答


hermes -t web,terminal -z "搜一下"   # 指定工具集


hermes -s skill1,skill2    # 预加载技能

模型管理

hermes model              # 交互式选择模型/提供商

hermes model list         # 列出可用模型


hermes model set openrouter/anthropic/claude-sonnet-4  # 设置默认模型


hermes fallback list      # 查看备用提供商链


hermes fallback add       # 添加备用提供商


hermes fallback remove    # 移除备用提供商

配置管理

hermes setup              # 交互式配置向导

hermes setup --quick      # 仅配置缺失项


hermes config             # 查看配置


hermes config edit        # 用编辑器修改配置


hermes config set model.provider openrouter  # 设置配置项

消息网关

hermes gateway            # 启动网关

hermes gateway install    # 安装为后台服务


hermes gateway status     # 查看网关状态


hermes gateway stop       # 停止网关


hermes send               # 脚本/CI 发送消息

技能管理

hermes skills list        # 列出已安装技能

hermes skills search <kw> # 搜索技能


hermes skills install <n> # 安装技能


hermes skills remove <n>  # 删除技能


hermes skills hub         # 浏览技能中心


hermes bundles create     # 创建技能组合（别名）


hermes curator status     # 后台技能维护状态

会话管理

hermes sessions list      # 列出历史会话

hermes sessions browse    # 交互式会话选择器


hermes sessions rename <id> <title>  # 重命名会话


hermes sessions export <id>  # 导出会话


hermes sessions prune     # 清理旧会话


hermes sessions delete <id>  # 删除会话

Cron 定时任务

hermes cron list          # 查看定时任务

hermes cron add           # 添加定时任务


hermes cron remove <id>   # 删除任务


hermes cron pause <id>    # 暂停任务


hermes cron resume <id>   # 恢复任务

看板

hermes kanban list        # 列出看板

hermes kanban create      # 创建看板


hermes kanban add         # 添加任务

Webhook

hermes webhook list       # 列出动态 webhook

hermes webhook subscribe  # 订阅 webhook

状态与诊断

hermes status             # 查看所有组件状态

hermes doctor             # 检查配置和依赖


hermes security           # 供应链安全审计（OSV）


hermes dump               # 导出设置摘要（支持用）

日志

hermes logs               # 查看 agent.log（最近50行）

hermes logs -f            # 实时追踪日志


hermes logs errors        # 查看 error.log


hermes logs --since 1h    # 过去1小时日志

调试

hermes debug share        # 上传调试报告

hermes backup             # 备份 ~/.hermes 到 zip


hermes import <file>      # 从 zip 恢复备份

认证管理

hermes login              # 登录推理提供商

hermes logout             # 退出登录


hermes auth list          # 列出所有凭据


hermes auth add <provider> # 添加凭据


hermes auth remove <p> <t> # 删除凭据

MCP 集成

hermes mcp servers        # 列出 MCP 服务器

hermes mcp add            # 添加 MCP 服务器


hermes mcp remove         # 移除 MCP 服务器

其他

hermes update             # 更新到最新版本

hermes version            # 查看版本


hermes proxy              # 启动 OAuth 代理


hermes pairing            # 管理 DM 配对码


hermes dashboard          # 启动 Web 仪表盘（:9119）


hermes dashboard --stop   # 停止仪表盘


hermes completion         # 生成 shell 补全脚本

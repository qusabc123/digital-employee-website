Hermes 示例命令

实战场景中的 Hermes 用法

日常对话

# 启动对话（自动加载当前目录上下文）


hermes


启动现代 TUI


hermes --tui


恢复上次会话继续聊


hermes -c

指定模型

# 使用特定模型启动


hermes -m anthropic/claude-sonnet-4.6


切换默认模型


hermes model set openrouter/anthropic/claude-sonnet-4.6


一行命令指定模型输出


hermes -m gpt-4o -z "写一份产品介绍"

加技能启动

# 预加载多个技能


hermes -s github-auth,github-pr-workflow


或逗号分隔


hermes --skills "obsidian,powerpoint"

消息网关场景

# 启动网关（同时服务 Telegram/Discord/Slack）


hermes gateway


通过脚本向 Telegram 发消息


hermes send --platform telegram "今日数据已更新"

Cron 定时场景

# 添加每日行业情报推送


hermes cron add


> 表达式: 0 9   *


> 任务: 搜索今天的 AI 行业新闻，总结后发到 Telegram


查看所有定时任务


hermes cron list

多代理并行场景

# 启动隔离工作树（并行代理）


hermes --worktree


子代理可以独立工作，互不干扰

工具集定制

# 只启用 web 和 terminal 工具


hermes -t web,terminal


查看所有可用工具集


hermes tools

调试排错

# 检查一切是否正常


hermes doctor


查看最近日志


hermes logs


实时监控


hermes logs -f


只看错误


hermes logs errors

日常运维

# 备份全部数据


hermes backup


更新到最新


hermes update


清理旧会话


hermes sessions prune


查看所有技能


hermes skills list

企业应用示例

场景一：客服机器人

# 1. 配置 Telegram Bot


hermes setup


2. 启动网关


hermes gateway


3. 客户在 Telegram 发消息 → Hermes 自动回复

场景二：行业情报监控

# 1. 添加每日 cron 任务


hermes cron add


2. 设置：每天早上9点搜索行业新闻


3. 自动推送到 Telegram/Discord

场景三：自动生成方案 PPT

# 配合 ppt-master + PowerPoint 技能


hermes -s powerpoint "根据这些数据生成10页商业计划书 PPT"

场景四：企业内部知识库

# 接入 Obsidian vault


hermes -s obsidian "在知识库里搜索关于XX客户的资料"

2. 行业一：电商/直播

优先级：★★★★★

2.1 行业画像

维度描述
典型企业淘宝/拼多多/抖音店铺、直播带货团队、私域电商
企业规模3-50人，大部分10人以下
决策者老板本人（运营出身）、运营总监
年营收100万-5000万
IT水平会用ERP/店小秘/旺店通，但整体数字化程度一般
认知水平听说过AI，部分人用过ChatGPT/DeepSeek
典型痛点客服成本高、咨询量大、回复不及时、内容产出慢
决策特征老板个人决策，效率高，但价格敏感
最佳触达渠道短视频、电商卖家社群、卖家朋友圈

2.2 核心痛点（由深到浅）

排序痛点描述频率
1客服人工成本高咨询量大，两班倒客服，月薪6000-8000x2人每天
2夜间无人值守晚上11点咨询没人回，漏单每天
3回复质量不稳定不同客服回复不一样，差评率高每天
4客服离职率高电商客服流动性大，培训成本高每月
5内容产出慢短视频脚本、详情页文案、直播话术每周
6客户画像不清客户来了也不知道是谁、买过什么每天
7售后跟进不及时退货/换货/退款处理慢每天
8数据分散多平台数据各自为战，统计困难每周/月

2.3 落地场景匹配

场景适配度优先级典型效果
智能客服★★★★★1st处理60-80%常见咨询，24h在线
营销内容生成★★★★☆2nd批量生成脚本/文案
数据报表★★★☆☆3rd多平台数据自动汇总
知识库★★☆☆☆4th商品知识/话术沉淀

2.4 差异化话术（切入）

电话/微信首次沟通

"老板你好，看你做电商的对吧？


最近很多电商老板找我们配AI客服。


原来两班倒的客服团队，现在AI能处理60-80%的常见问题，


晚上11点有人来问，AI自动回复自动记录。


起步3500块，不到一个客服半个月工资。


怎么样，有兴趣了解一下吗？"

短视频方向

"电商老板注意了！


你花8000一个月请的客服，晚上10点之后就不在了？


但你的客户晚上12点还在下单。


我们给xx店铺配了AI客服，


晚上11点-早上8点处理的咨询量，


占了全天的30%以上。


3500块，把这个时间段接住。


合不合算你自己算。"

朋友圈文案

电商朋友说：最怕晚上来大单，客服不在。


现在AI帮他兜底了：自动回复、自动报价、自动记录。


早上起来一看，昨晚成交了3单。


3500配的，第一天就回本了。

2.5 价值量化

场景原来成本AI方案成本节省
智能客服（单店）1个客服月薪5000-8000S1 3500 + API 200/月第一年省3万+
营销内容（月产100条）1个文案月薪6000+S2 6000 + API 300/月第一年省5万+
双11/618期间临时招客服3人x3000AI零成本增量省9000

2.6 常见质疑与应对

质疑应对
"AI回消息会不会很死板？""我们会根据你的风格定制话术，客户区分不出来是不是AI。而且遇到AI不会的问题，自动转人工。"
"客户发现是AI会不会反感？""客户只在乎能不能解决他的问题，不在乎谁回的。而且很多客户更喜欢AI，因为不用等。"
"我们已经在用自动回复工具了""了解一下您用的什么工具？我们跟工具的区别是：我们是AI驱动的，能理解客户问题的意思，不是关键词匹配。而且可以深度定制。"

2.7 推广渠道侧重

  1. 短视频（抖音/视频号）— 打"半夜咨询漏单"痛点
  2. 电商卖家社群 — 精准触达
  3. 朋友圈 — 案例展示
  4. 异业合作 — 代运营公司/ERP服务商推荐

3. 行业二：二手车/汽配

优先级：★★★★★

3.1 行业画像

维度描述
典型企业二手车行、汽配批发商、汽修连锁店
企业规模3-20人
决策者老板/店长（通常懂车、懂生意但不懂技术）
年营收200万-5000万
IT水平低，有的在用"车300""查博士"等工具，有的还在用本子记
认知水平部分人听说过AI，但觉得跟自己没关系
典型痛点车源管理混乱、客户咨询量大、出价不统一、回访不及时
决策特征老板个人决策，看重"能不能帮我多卖车"
最佳触达渠道二手车市场地推、行业展会、朋友圈

3.2 核心痛点

排序痛点描述
1客户咨询量大量重复每天十几二十个人问"XX车多少钱""哪年的"
2回复速度跟不上咨询一多，回复慢，客户跑了
3出价不统一不同销售报不同价，影响成交
4跟进回访不及时客户来看过车走了之后没人跟进
5车源信息变化快收车/卖车频繁更新，信息更新跟不上
6库存盘点费时手上有什么车、在哪、什么价，每天靠人记
7客户数据流失看过车的客户没有系统记录，无法再营销

3.3 落地场景匹配

场景适配度优先级典型效果
智能客服★★★★★1st自动回复询价，24h在线
数据报表★★★★☆2nd车源/库存/询价数据自动汇总
文档自动化★★★☆☆3rd收车合同/交易协议自动生成

3.4 差异化话术

首次沟通

"王总好，我专做二手车行AI方案的。


最近好几个二手车老板找我们配了AI客服，


效果挺明显的。


原来微信上10个人问车，最多能接住3-4个，


剩下的忙起来就忘了回。


AI帮你自动回：什么车、多少钱、哪年上牌、在哪看车。


客户走了还能自动跟进回访。


起步3500块，3-7天就能配好。


"

话术要点（二手车老板关心的）

  • 不要讲技术名词，讲"卖车""接客""不跑单"
  • 讲同行案例最有效
  • 用"昨天晚上11点来了个客户，AI接了"开头

3.5 价值量化

指标改善幅度计算方式
询价回复率从40%→95%AI自动回复所有询价
跟进回访从不跟→自动跟客户3天后自动回访
漏单率从30%→5%夜间/忙碌时不再漏单
月均多成交1-3台按询价→试驾→成交转化率

3.6 推广渠道侧重

  1. 二手车市场直接拜访/地推
  2. 二手车行业展会/联谊会
  3. 二手车商社群
  4. 朋友圈案例展示（最有效）

4. 行业三：本地服务

优先级：★★★★☆

4.1 行业画像

维度描述
覆盖范围餐饮、美容美发、装修/建材、家政、维修、宠物服务
企业规模1-10人
决策者老板本人（通常在店里）
典型痛点预约管理乱、客户咨询分散在微信/电话、回访不及时
决策特征老板说了算，价格敏感，看重"立竿见影"

4.2 核心痛点

痛点描述
电话咨询多一天接几十个电话问"多少钱""还有没有位置"
预约易冲突本子记/微信记，容易漏单撞单
回访基本不做知道应该做回访但没时间做
评价管理难客户发到不同平台，看不过来
员工流动大培训成本高，知识没法沉淀

4.3 差异化话术

"老板您好，我看您这家店开了挺久了，


平时是不是经常接到电话问'多少钱''几点开门'这种问题？


问的人多了，忙起来就容易忘回。


我们给本地商家配的AI客服，


能自动接电话、回微信、帮您记录预约。


客户几点来、做什么项目、多少钱，AI自动记。


起步就3500，不到一个员工半个月工资。


"


（更适合的切入方式：直接对着实体店老板，用"你店里现在最忙的活是什么"开场）

4.4 推广渠道侧重

  1. 本地生活社群（美团/点评老板群）
  2. 地推（写字楼下的餐饮街、社区商业街）
  3. 同城短视频（抖音同城、本地生活号）

5. 行业四：传统制造业

优先级：★★★★☆

5.1 行业画像

维度描述
典型企业机械配件厂、五金加工、电子组装、包装印刷
企业规模10-200人
决策者老板/厂长/生产经理
典型痛点图纸/文档管理乱、经验传承难、质量报告手工写
决策特征决策周期长、看重稳定和安全、对价格不敏感

5.2 核心痛点

排序痛点描述
1文档/图纸管理混乱文件散落各处，新员工找不到
2老员工经验无法传承干了20年的师傅，经验全在脑子里
3报价/合同反复人工操作客户询价→人工查参数→出报价
4质检报告手工填写每天几十份，月底汇总头疼
5新品说明书/培训资料每出一个新品，文档全靠写

5.3 落地场景

场景适配度优先级
知识库★★★★★1st
文档自动化★★★★☆2nd
数据报表★★★☆☆3rd

5.4 差异化话术

"老板，我看你们厂做XX配件做了好多年了吧？


有件事您肯定有体会：


厂里最有经验的老师傅，干了一辈子，脑子里东西最值钱，


但他退休了怎么办？


我们做的事很简单：把老师傅的经验、工艺流程、产品参数


做成一个AI知识库。


新员工随时用手机问，AI自动回答。


不用翻文件、不用找老师傅。


起步3500一个场景。


"

5.5 注意事项

  • 制造业老板决策周期长（2-4周），需要有耐心
  • 通过商会/工业园渠道触达效率最高
  • 案例最好用制造业的，不要用电商案例（对方会觉得跟我不一样）

7. 行业六：律师/会计事务所

10. 跨行业通用：客户分级标准

10.1 企业客户分级

级别定义特征策略
S级高意向+高预算明确需要、有预算、决策快优先排期、亲自跟
A级明确意向有需要、预算适中重点跟进、快速推进
B级潜在意向有兴趣、不确定要不要教育培养、保持触达
C级了解阶段刚接触、问得多加好友、朋友圈养
D级无效同行/非目标/无需求不投入精力

10.2 客户跟进节奏

级别跟进频率跟进方式多久不回放弃
S级每2天1次电话+微信持续跟
A级每3-4天1次微信为主2周
B级每周1次微信/朋友圈1个月
C级每月1次朋友圈 + 偶尔私信3个月
D级不跟进按需—

10.3 跟进记录的标准化

每次跟进后，在客户管理表中记录：

时间：2026-06-03 14:30


方式：微信私信


客户反馈：问了价格，说考虑


后续动作：发案例，约3天后跟进


跟进人：倪锦


状态：B级→A级 ↑


备注：客户对智能客服有兴趣，可能还有数据报表需求

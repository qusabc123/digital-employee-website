L0 曝光/触达

客户状态

  • 对AI有模糊认知（听说过ChatGPT/文心一言/DeepSeek）
  • 知道AI能做事，但不知道跟自己有什么关系
  • 或者：完全没想过AI跟自己有什么关系
  • 或者：已经搜索过AI相关服务，处于对比阶段

触达方式（对应模块一各渠道）

  • 朋友圈刷到你的内容
  • 短视频推荐流刷到
  • 微信群看到分享
  • 展会/讲座遇到你
  • 朋友推荐
  • 搜索"AI企业服务"看到

此阶段唯一目标

让客户产生"这跟我有关系"的第一印象

—— 不是让他马上掏钱，而是让他想了解更多

各渠道的"钩子"标准

每个渠道的头3秒/前3行必须回答客户内心的两个问题：

  1. "这跟我有什么关系？"
  2. "继续看下去对我有什么好处？"

合格钩子示例：

  • "用半个月工资，给公司配一个24小时在岗的AI员工"
  • "你公司有没有月薪5000、实际产出500的岗位？"
  • "昨天一个客户给我发了个截图……"
  • "中小企业用AI，只需要做好这一步"

失败钩子示例：

  • "上海锦霓鲤锦网络科技有限公司专注于AI智能体定制服务……"（上来就自我介绍）
  • "AI是什么？ChatGPT、GPT-4……"（从定义讲起）
  • "2026年AI Agent市场规模将超过300亿美元……"（只讲行业不讲他）

广告/推广内容核检清单

每次发布内容前，检查以下问题：

  • [ ] 前3秒/前3行能否让对方觉得"跟我有关"？
  • [ ] 对方看完会不会想知道更多？
  • [ ] 对方知道下一步该做什么（评论/私信/加微信）？
  • [ ] 是不是用一个真实场景代替了空洞描述？
  • [ ] 有没有明确的"下一步行动"？

L1 初步沟通

客户状态

  • 通过某种方式联系上了你（私信/加微信/电话）
  • 好奇心驱动，但还没下定决心
  • 可能是随便问问，也可能是真有意向
  • 最脆弱的时候：随时可能消失/被竞品抢走

此阶段唯一目标

判断客户画像 + 建立初步信任 + 约到免费诊断

不是：给他报价、给他讲完整方案、说服他马上买

客户初筛分级（立刻判断）

等级特征策略
A级（高意向）主动问价格、明确说自己有需求、说了自己的行业/规模加快节奏，直接约诊断
B级（中意向）对AI感兴趣、问了但問題模糊、可能在对比给案例+引导，不急但保持跟进
C级（低意向）"先了解一下"、"随便看看"、不透露信息加好友保持朋友圈触达，暂不主动跟进
D级（无效）竞品/同行、完全不是目标客户、推销者礼貌拒绝或不加

私信首次沟通话术（逐字稿）

场景A：客户从私信/评论主动联系你

客户："你好，想了解一下AI员工"


你：


"您好老板！感谢关注 🙌


方便问一下您是什么行业、目前公司多少人？


我发针对性的案例给您参考，


现在加您好友了，通过一下~"



（同时发好友申请）

场景B：你主动加客户好友后

"老板您好，我是倪锦，做AI数字员工企业定制的。

刚才在xx群/展会上有交流过 👋



简单了解一下您的情况：


① 公司主要做什么业务？


② 目前几个员工在使用AI？


③ 目前有遇到什么效率上的困扰吗？



知道这些我才能给您有针对性的建议。


不着急，慢慢聊~"

场景C：客户主动问价

客户："你们那个S1 3500是什么？"


你：


"S1是单场景方案，


比如只做智能客服、或者只做文档自动化，


适合先试一个场景看看效果。



不过不一定要先定方案，


我的建议是先免费帮您诊断一下：


您公司哪个岗位最适合先配AI、


配了能省多少时间/多少钱。



这周有空聊聊吗？


先出个报告，有感觉了再做决定也不迟。"

场景D：客户说"考虑考虑"

"明白，AI这事确实不能急。

这样，我发您几个同行案例看看，


您先了解一下同行业的效果，


有感觉了我们再聊？



或者这周有空的话，


免费上门帮您诊断一下出个报告，


零成本看看AI能帮您做什么。"

初步沟通信息收集表

以下是50秒内必须问出来的信息：

信息问法为什么重要
行业/业务"您公司主要做什么业务？"决定场景推荐方向
规模"目前公司几个人？"判断决策能级/预算
痛点"目前最头痛的效率问题是什么？"精准定位场景
预算范围"对AI投入有大概预算吗？"推荐S1/S2/S3
决策角色"这个事是您说了算还是需要跟合伙人商量？"判断决策链长度
时间节点"希望什么时候能上线？"判断紧迫度

反对意见处理

反对1："太贵了"

"了解。3500是入门价格，对比大厂定制一个场景2-5万，

我们的价格其实挺实在的。



而且可以先免费诊断，出个报告看看能省多少。


如果AI一年能帮您省1万+，那3500就是稳赚的投资。



您说呢？"

反对2："我不懂AI，怕用了不会"

"这个您不用担心，这也是我们跟卖软件最大的区别。

我们全程陪跑：从诊断到安装到培训到维护，


您不用懂AI，您只需要告诉我想解决什么问题就行。



就像您买一台新机器，您不需要懂机械原理，


懂怎么用、能产出就行了。"

反对3："我想再等等，看看别人怎么用"

"理解。很多老板都这么说。


不过有个数据供您参考：


先用的企业效率提升20-35%，后用的可能只是在追差距。


而且现在是免费诊断阶段，没有成本。



要不这样，我先免费帮您出个报告，


您看看AI在您公司能做什么，


再决定做不做，怎么样？"

反对4："我先跟合伙人商量一下"

"应该的。这样，我整理一份简版方案您带回去给合伙人看，

包括做什么、花多少钱、能省多少，


一目了然。



您给我个邮箱，我发您一份。"

初步沟通后跟进节奏

情况跟进策略
答应约诊断当天定时间，发日程确认
说"想想"24h后发一个案例，48h后问一次，1周后最后一次，转入长期触达
说"不需要""好的，有问题随时找我"，保持朋友圈触达
未回复72h后补一条，再不回复转入朋友圈触达
说"发资料看看"发精心准备的资料（不是转个链接），提醒"看完了告诉我，有问题随时聊"

L1 到 L2 的转化标准

  • [ ] 获取了客户行业/规模/痛点基本信息
  • [ ] 客户接受了"免费诊断"的价值
  • [ ] 约定了诊断时间（远程或上门）
  • [ ] 客户没有明显的反对意见未被处理

L2 免费诊断

客户状态

  • 愿意花1-2小时跟你聊他的业务
  • 已经有一定信任基础
  • 但仍有顾虑："说了不做会不会不好意思"

此阶段唯一目标

呈现专业度 + 找到1-2个高价值场景 + 让客户觉得"这人有水平"

不是：现场报价、现场说服、做完整方案

诊断前准备（15min）

2.1 客户背景复习

  • [ ] 再看一遍初步沟通记录（行业/规模/痛点）
  • [ ] 搜索该行业的AI落地案例（至少准备2个同行案例）
  • [ ] 准备该行业高频场景的初步想法
  • [ ] 如果上门，查好路线和时间

2.2 工具包检查

  • [ ] 笔记本电脑（有演示内容）
  • [ ] 笔记本和笔（不要用手机记，显得不专业）
  • [ ] 名片（再给一次）
  • [ ] 案例打印版（如果有）
  • [ ] 手机录音（征得同意后）

2.3 诊断议程

时段内容目的
0-5min寒暄+说明今天的目的放松氛围
5-25min调研业务流程找痛点和场景
25-35min现场演示（如果有条件）建立信心
35-45min初步诊断反馈呈现价值
45-50min讲下一步流程自然引入方案阶段
50-60minQ&A+道别留下好印象

诊断调研问题清单（逐题）

开场（5min）

"王总，感谢您今天抽时间。

我今天来的目的很简单：


了解一下您公司的业务流程，看看哪些环节可以用AI优化。


诊断是免费的，做完后我会出一份评估报告给您。



整个过程大概1小时左右，


我们会聊您公司的日常运营、哪个环节最费时间、


目前遇到的效率问题。



来，先从您的业务开始说吧——


您公司目前主要做什么？"

核心问题（25min）

业务全貌：

  1. "公司目前线上线下都有吗？占比大概怎样？"
  2. "日常客户咨询量大概多少？什么渠道来的？"
  3. "有没有重复性高的手工工作？比如做报表、写报价、填表格？"

痛点深挖：

  1. "目前团队里，哪个岗位你觉得最累或者最值？"
  2. "如果现在让你选一个岗位用AI替代一部分工作，你最先想到哪个？"
  3. "公司目前有没有用任何软件/工具来做自动化？"

技术准备度：

  1. "公司目前数据大多在哪里？Excel？ERP系统？还是纸上记？"
  2. "员工对新技术接受度怎么样？"

决策逻辑：

  1. "如果这个AI能证明帮您省了XX时间/钱，您会考虑做吗？"
  2. "主要是担心什么？效果？成本？员工抵触？安全？"

诊断结束前（15min）

"好的，今天聊下来我觉得有几个点可以优化：


第一，XX环节（如客户咨询）的重复性很高，


AI可以自动处理60-80%的常见问题。



第二，XX环节（如数据汇总）目前靠人工，


AI可以自动完成，而且更准确。



第三，XX环节（如合同/报价）可以自动化生成。



我会把详细的分析和方案写进评估报告，


2天内发给您。



到时候我们约个时间再聊一次，


我给您看看具体怎么做、多少钱、多久能上线。



您看这个节奏可以吗？"

拒绝诊断后的处理

场景：客户在L1说约诊断，到临头推辞

"没关系，可以理解。要不这样：

我远程帮您梳理一下，您不用特意安排时间。


你把目前最耗时的2-3个工作环节跟我说说，


我出个初步分析发您看看？



也是免费的，发您看看值不值得深入聊。"

场景：诊断中客户表现冷淡/不确定

"没关系，AI不一定适合所有企业。

但至少今天聊下来，我发现XX环节确实可以优化，


即使不找我们做，我也建议您关注一下这个方向。



报告我还是会发您，


以后有需求了随时找我。"

报告交付SOP

诊断后24h内 → 报告初稿完成

诊断后48h内 → 发给客户 + 约"方案讲解会"


讲解会 → 30min电话/见面


前10min：讲报告内容


中10min：讲建议方案


后10min：讲报价+回答疑虑


讲解会后 → 发正式报价单

L2 到 L3 的转化标准

  • [ ] 完成了至少1小时的业务调研
  • [ ] 交付了《AI诊断评估报告》
  • [ ] 客户确认了至少有1个场景他认为有价值
  • [ ] 约定了方案讲解/报价时间

L3 方案报价

客户状态

  • 已经看到了诊断报告，认可了AI的价值
  • 到了"要掏钱"的环节，心理阻力最大
  • 开始对比：价格、性价比、风险、其他供应商

此阶段唯一目标

让客户觉得"值" + 消除最后顾虑 → 促成签约

关键认知：客户买的不是AI，买的是"省事/省钱/省心"

方案设计原则

原则说明
从诊断报告出发方案紧贴诊断中发现的问题
不要过度承诺说清楚做什么、不做什么、预期效果
给选择提供2-3个方案（S1/S2/S3或不同场景组合）
量化价值帮客户算清楚：投入X元 = 每年省Y元/小时
降低决策门槛承诺先做、效果不好可调整

报价策略

S1 报价策略（3500元）

适用：预算有限、想先试水、单个场景明确

话术：

"S1 3500元，相当于一个员工半个月工资。

包：诊断+开发+部署+1个月维护。


一个场景完整跑通。



如果您试了发现有效果，


后续可以升级到S2或者再加其他场景。


如果效果不如预期，我们按S1收了，您损失也不大。


"

S2 报价策略（6000元）

适用：有3-5个场景需求、追求性价比

话术：

"S2 6000元，相当于一个员工一个月工资。

包3-5个场景，平均每个场景才1200-2000元。


比S1划算很多。



我建议您先选3个最迫切的场景做，


等验证了效果可以再加。"

S3 报价策略（50000/年）

适用：有长远规划、所有场景都想覆盖、预算充足

话术：

"S3 5万一年，不限场景、不限次数。

相当于一个月4000多，比招一个员工省多了。


而且我们全年维护、随时迭代。



如果您公司有10个以上员工，


基本S3是最划算的选择。"

报价中常见反对意见处理

反对1："比我想的贵"
"理解。不过您算一笔账：

目前XX员工做这个工作，每月工资XX元，


一年下来就是XX元。


AI配上去之后，效率提升后相当于省了XX%的时间。


一年下来其实回本了。



而且我们是先诊断、后出方案、不滿意可以调整。


试错成本很低。"

反对2："别家比你便宜"
"方便说说是哪家吗？我了解一下。


（听完后）


不同公司报价差异主要在服务范围：


有些只卖软件不管实施，


有些只做咨询不做落地。



我们是从诊断到开发到培训到维护全包。


而且我们是签正规合同、开发票的。



您可以对比一下总成本，


便宜的方案如果配完之后没人用，


那才是最贵的。"

反对3："能不能再便宜点"
预设折扣权限：

    

  • S1：不降价（起步价，没有空间）
    • 

  • S2：可送1个月运维（价值500元）
    • 

  • S3：可做到4.5万（心理价位）或送季度运维
    • 




话术：


"不瞒您说，我们的价格已经很低了。


大厂定制一个场景2-5万，我们3500起步。


这样吧，今天我做个主：


如果今天签约，我送您XX（运维/方案升级/再加一个场景）。"

反对4："效果不好怎么办"
"所以我们做的是先诊断再出方案，

不是瞎配的。



而且上线后我们会跟踪1个月效果，


如果效果不达标，我们负责调整优化到满意为止。



签合同的时候也会把交付标准写清楚，


达不到标准我们继续改，这个您放心。"

逼单技巧

场景：客户犹豫不决

（不要逼单）

"王总，我完全理解。


买AI服务不是买包烟，需要考虑。



这样吧，我说一下我们的排期：


最近我们手上还有XX个项目在做，


如果您这周确定，我们可以优先排您。


如果这周定不下来，可能要等到下个月中旬。



您看要不要这周先签了，我们下周就开始做？


不需要全额付，首付50%，验收后再付尾款。"

场景：客户说"我跟合伙人商量"

"应该的。不过我建议您跟合伙人说的时候，

注意三个核心点：


    

  1. 成本：3500/6000/5万，分别的投入
    2. 

  2. 效果：诊断报告里说的XX场景能省XX时间/钱
    3. 

  3. 风险：先免费诊断、效果不好可调整、有正规合同
    4. 




我帮您整理一份简版的方案说明，


您直接转发给合伙人看就行。"

L3 到 L4 的转化标准

  • [ ] 客户清晰了解方案内容
  • [ ] 客户对报价没有重大异议
  • [ ] 客户知道了自己的主要疑虑且得到了解答
  • [ ] （最好）约定了签约时间

L4 签约付款

此阶段唯一目标

以最高效率完成签约和收款，确保客户无后顾之忧

签约流程

客户确认 → 发电子版合同 → 客户确认合同条款

↓


客户盖章/签字 → 回传合同


↓


客户付款 → 我方确认到账 → 开具发票


↓


拉项目群 → 进入交付阶段

合同关键条款说明

条款内容说明
服务范围具体哪几个场景写清楚，避免扯皮
交付周期3-7个工作日留buffer
付款方式首付50%+验收后付50%降低客户风险
售后保障1个月免费维护超出1个月按S+计
知识产权Agent归属客户重要信任点
保密协议客户数据保密安全顾虑的最后一关
违约责任双方免责条款正规感

收款方式

  • 对公转账（最正规，可开发票）
  • 微信/支付宝（小额S1可用）
  • 分期付款（S3可谈季付）

签约后的动作

签约后24h内

✓ 拉项目群（你+客户+技术）


✓ 发项目启动邮件/消息


✓ 同步项目排期表


✓ 预约环境搭建时间



签约后48h内


✓ 技术开始对接


✓ 客户确认数据源


✓ 排期确认

L5 交付上线

详细SOP见 [模块五：交付SOP](./模块五_交付SOP标准操作手册.md)

此阶段关键点

  1. 超预期沟通 — 每天在项目群汇报进度
  2. 客户参与 — 让客户看到、摸到、体验到
  3. 验收标准清晰 — 什么算"做完了"要提前说好
  4. 培训到位 — 客户会用才是真交付

验收后的黄金72h

  • 第1天：正式上线 + 密切关注运行
  • 第2天：检查效果 + 微调
  • 第3天：收集客户反馈 + 确认满意
  • 第4天：发"上线报告" + 引导转介绍

类型方案话术
